# Feedback Radicalmente Sincero

# Reflexión sobre la aplicación del feedback durante el proyecto

## Introducción

Uno de los aspectos más valiosos del desarrollo de este proyecto fue comprender la importancia del feedback como una herramienta para el aprendizaje y la mejora continua. A lo largo de las distintas auditorías realizadas para KLYN Dress, cada revisión del contenido representó una oportunidad para detectar aspectos que podían optimizarse, tanto en la calidad del análisis como en la forma de comunicar y documentar el trabajo.

En lugar de interpretar las observaciones como críticas personales, decidí utilizarlas para revisar mis decisiones, reorganizar la información y fortalecer la estructura general del proyecto.

---

## Aplicación del feedback

Durante el desarrollo del proyecto fui realizando revisiones constantes sobre el contenido elaborado. Estas revisiones me permitieron identificar oportunidades de mejora relacionadas principalmente con la organización de la documentación, la claridad en la comunicación y la estructura de las auditorías.

A partir de estas observaciones implementé distintas mejoras, entre ellas:

- Reorganizar la estructura de los documentos para facilitar su lectura.
- Unificar el formato utilizado en las diferentes auditorías.
- Mejorar la redacción para que pudiera ser comprendida tanto por personas con conocimientos técnicos como por lectores sin experiencia previa.
- Incorporar documentación complementaria, como el análisis post-mortem y este registro de reflexión.

Cada modificación realizada buscó mejorar no solamente el resultado final, sino también el proceso de trabajo.

---

## Mentalidad de crecimiento

Este proyecto reforzó la importancia de mantener una actitud abierta al aprendizaje. Comprendí que recibir observaciones no significa que el trabajo esté mal realizado, sino que siempre existen oportunidades para perfeccionarlo.

Adoptar una mentalidad de crecimiento implicó aceptar que la mejora forma parte del proceso y que cada revisión contribuye a desarrollar mejores prácticas de documentación, comunicación y organización.

---

## Aprendizajes obtenidos

Como resultado de esta experiencia, identifiqué varios aprendizajes que aplicaré en futuros proyectos:

- Solicitar revisiones antes de considerar finalizado un trabajo.
- Documentar cada decisión importante para facilitar futuras modificaciones.
- Mantener una estructura organizada desde el inicio del proyecto.
- Considerar el feedback como una fuente de aprendizaje y no como una crítica personal.
- Priorizar una comunicación clara, objetiva y orientada al lector.

---

## Conclusión

La aplicación de feedback radicalmente sincero permitió mejorar tanto el contenido como la forma de presentar el proyecto. Más allá de las auditorías desarrolladas para KLYN Dress, esta experiencia fortaleció mi capacidad para analizar mi propio trabajo de manera crítica, incorporar sugerencias y convertir cada revisión en una oportunidad de crecimiento profesional.

Entendí que la mejora continua no depende únicamente del conocimiento técnico, sino también de la disposición para escuchar, reflexionar y evolucionar a partir de las experiencias vividas.
