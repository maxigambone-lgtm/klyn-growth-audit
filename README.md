 # 📊 KLYN Growth Audit

> **Caso de estudio sobre Comunicación en Entornos Digitales y Mentalidad de Crecimiento aplicado a KLYN Dress.**

---

## 📖 Descripción

Este repositorio documenta el desarrollo de un caso de estudio basado en las auditorías realizadas para **KLYN Dress**, una marca de indumentaria urbana.

El proyecto analiza un desafío relacionado con la organización de la documentación y muestra cómo la aplicación de herramientas como GitHub, el control de versiones y el análisis post-mortem permitieron mejorar el proceso de trabajo, fortalecer la comunicación y desarrollar una mentalidad de crecimiento.

El objetivo no fue únicamente resolver un problema, sino documentar el aprendizaje obtenido para generar un proceso más eficiente y sostenible.

## 🎯 Objetivos del proyecto

- Documentar un desafío real dentro del proyecto KLYN Dress.
- Aplicar una metodología de mejora continua.
- Implementar un análisis post-mortem.
- Utilizar GitHub como sistema de control de versiones.
- Desarrollar documentación clara para audiencias técnicas y no técnicas.
- Evidenciar una mentalidad de crecimiento mediante la reflexión y el aprendizaje.
