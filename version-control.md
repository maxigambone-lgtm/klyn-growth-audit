# Control de Versiones

Durante el desarrollo de este proyecto se utilizó GitHub como sistema de control de versiones para registrar la evolución de la documentación.

Cada modificación importante fue registrada mediante commits, permitiendo mantener un historial claro de los cambios realizados.

## Principales cambios registrados

- Creación del repositorio.
- Configuración de GitHub Pages.
- Desarrollo del blog técnico.
- Elaboración del análisis Post-Mortem.
- Incorporación de la reflexión sobre Feedback.
- Organización final de la documentación.

El uso de control de versiones permitió mejorar la trazabilidad del proyecto y facilitar futuras modificaciones.
